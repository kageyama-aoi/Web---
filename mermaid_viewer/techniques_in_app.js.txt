Mermaid Live Viewer (`app.js`) で使用されている技術・テクニック解説
================================================================

このファイルは、`app.js` に実装されている主要なプログラミング技術やブラウザAPIについて解説します。

### 1. 基本的な構造

- **即時実行関数 (IIFE)**: `(function(){ ... })();` という構文でコード全体を囲んでいます。これにより、変数や関数がグローバルスコープを汚染するのを防ぎ、コードの独立性を高めています。
- **モジュール (ESM)**: `import { ... } from './samples.js';` のように、ES Modules を利用してサンプルデータを別ファイルから読み込んでいます。これにより、関心事の分離を進めています。
  - **考え方**: 巨大な1つのJSファイルで全てを管理するのではなく、機能ごとにファイルを分割（モジュール化）する仕組みです。「道具箱」のように、役割ごと（サンプルデータ、UI操作、ファイル処理など）にコードを整理します。
  - **`export` (公開)**: `js/samples.js` の中で `export const SAMPLES = ...` と書くことで、「この `SAMPLES` という変数は、他のファイルから使っていいですよ」と公開（エクスポート）しています。
  - **`import` (利用)**: `js/app.js` の中で `import { SAMPLES } from './samples.js';` と書くことで、「`samples.js` が公開している `SAMPLES` を、このファイルで使います」と宣言（インポート）しています。
  - **`type="module"` (宣言)**: HTML側で `<script src="js/app.js" type="module">` と指定することが不可欠です。これにより、ブラウザに対して「このJSファイルはモジュールとして扱ってください」と伝えます。
  - **効果**:
    - **保守性の向上**: 関連するコードが1つのファイルにまとまるため、修正箇所が見つけやすくなります。
    - **再利用性の向上**: 便利な関数をまとめたモジュールは、他のプロジェクトでも再利用できます。
    - **可読性の向上**: メインの `app.js` は、各モジュールを読み込んで繋ぎ合わせる役割に集中でき、全体の処理の流れが追いやすくなります。

### 2. DOM操作とイベント処理

- **DOM要素の取得と操作**: `document.querySelector` を短縮したヘルパー関数 `$` を定義し、効率的にDOM要素を取得しています。取得した要素の `textContent` や `innerHTML`、`value` を操作してUIを動的に更新しています。
- **イベントリスナー**: `addEventListener` を使い、ボタンのクリック (`click`)、テキストエリアの入力 (`input`)、セレクトボックスの変更 (`change`)、キーボードショートカット (`keydown`) など、多彩なユーザー操作を検知して対応する処理を実行しています。

### 3. 非同期処理

このアプリケーションでは、ユーザーを待たせないための「非同期処理」が効果的に使われています。
料理に例えると、**同期処理**は「パスタを茹でている間、鍋の前でずっと立ち尽くす」ようなもの。その間、他の作業は一切できません。
一方、**非同期処理**は「パスタを茹で始めたらタイマーをかけ、その間にサラダを作る」ようなもの。タイマーが鳴ったら（処理が終わったら）次の作業に移ります。これにより、アプリが固まらず（フリーズせず）快適に操作できます。

- **`async/await`：読みやすい非同期処理の書き方**
  - `async function render(){ ... }` のように書くことで、「この関数の中では、時間がかかる処理を待つかもしれません」と宣言します。
  - `await window.mermaid.render(...)` のように書くことで、「`render` が完了するまでここで待ってください。でもアプリ全体は止めないでください」と指示します。
  - **効果**: 料理のレシピのように上から下に読める直感的なコードでありながら、裏ではしっかり非同期で動いてくれるため、開発しやすく、かつユーザー体験も損ないません。

- **`Promise`：「未来の結果」を約束する引換券**
  - `async/await` が待っている処理の正体が `Promise` です。「処理が終わったら、成功した結果か、失敗した理由のどちらかを必ず渡します」という**約束（引換券）**のようなものです。
  - `svgToPng` 関数では、`new Promise(...)` を使って、画像変換という古くからある非同期処理を、`async/await` で扱える現代的な `Promise` 形式に変換（ラップ）しています。
    - 処理が成功したら `resolve(結果)` を呼び出す（引換券が当たりになる）。
    - 処理が失敗したら `reject(エラー)` を呼び出す（引換券がハズレになる）。

- **`setTimeout` とデバウンス：賢い「待った！」で処理を効率化**
  - `setTimeout` は「指定した時間後に、この処理を実行して」と予約するシンプルなタイマー機能です。
  - このアプリでは、これを応用した**デバウンス (Debounce)** というテクニックが使われています。
  - **例**: ユーザーがエディタに文字を1文字入力するたびにプレビューを更新すると、非常に重くなります。
  - **デバウンスの動き**:
    1. ユーザーが文字を入力するたびに、「400ミリ秒後にプレビューを更新する」という予約を入れます。
    2. ただし、予約を入れてから400ミリ秒以内に**次の文字が入力されたら、さっきの予約はキャンセル**し、新しい予約を入れ直します。
    3. 結果として、ユーザーの**入力が400ミリ秒間止まったときだけ**、プレビューの更新が1回だけ実行されます。
  - **効果**: 無駄な処理を劇的に減らし、スムーズな入力体験を実現しています。

### 4. ブラウザAPI (Web APIs) の活用

このアプリケーションは、ブラウザが標準で提供する多くの強力なAPIを駆使しています。

- **LocalStorage**: エディタに書かれたコード、選択されたテーマ、UIの配色設定などをユーザーのブラウザに保存するために `localStorage.setItem()` と `getItem()` を使用しています。これにより、ユーザーがページを再読み込みしても前回の状態が復元されます。
    - `.mmd` やSVG/PNGファイルを保存する際に、`Blob` オブジェクトを生成し、`URL.createObjectURL()` でダウンロード用のURLを動的に作成しています。
    - 「読み込み」ボタンでは、`input[type=file]` で選択されたファイルを `File API` を使って読み込んでいます。
- **Canvas API**: SVGからPNGへの変換処理 (`svgToPng`) で `canvas` を利用しています。SVGを一度 `<canvas>` 要素に見えない形で描画し、その内容を `toDataURL()` メソッドでPNG形式のデータURLに変換しています。
- **matchMedia**: OSのダークモード設定を検知 (`prefers-color-scheme: dark`) するために `window.matchMedia()` を使用し、UIの配色を自動で切り替える機能を実現しています。

### 5. データエンコーディング

- **Base64**: `btoa()` (エンコード) と `atob()` (デコード) を使用しています。
- **URIComponent**: `encodeURIComponent()` と `decodeURIComponent()` を使用しています。
- これらを組み合わせることで、日本語などのマルチバイト文字を含むMermaidコードを、URLで安全に扱える英数字記号のみの文字列に変換しています。

### 6. その他のテクニック

- **正規表現**: `compatFixGitGraph` 関数で、古いバージョンの `gitGraph` 構文を新しいバージョンに自動変換するために正規表現による文字列置換を行っています。
- **フォールバック処理**: `downloadSvg` 関数などで、推奨される方法（Blobダウンロード）が失敗した場合に備えて、代替案（Data URLを新規タブで開く、クリップボードにコピーする）を段階的に試す堅牢な実装になっています。

### 7. 外部ライブラリ連携

- **Mermaid.js**: HTMLの`<script>`タグで読み込まれた `mermaid` ライブラリのグローバルオブジェクト (`window.mermaid`) を直接呼び出し、構文解析 (`parse`) やSVGへのレンダリング (`render`) を行っています。

---

**まとめ**

この `app.js` は、単なるDOM操作にとどまらず、モダンブラウザが持つ多彩なAPIを組み合わせることで、サーバーサイドの力を借りずにリッチな機能（状態の永続化、ファイル操作、画像変換、共有機能など）を実現している好例です。
