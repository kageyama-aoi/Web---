# プルダウンメニューの表示不具合 解決手順

## 1. 問題の原因

`index.html` のプルダウンメニューが表示されないのは、ブラウザのセキュリティ機能（CORSポリシー）が原因です。

ローカルのHTMLファイル (`file:///...` で始まるURL) から、JavaScript (`fetch`) を使って別のローカルファイル (`presets.json`) を読み込むことは、セキュリティ上の理由から多くのブラウザでブロックされます。

## 2. 解決方法

この問題を解決するには、ローカルにWebサーバーを立てて、`http://...` 経由でファイルにアクセスする必要があります。

以下の手順に従って、ローカルWebサーバーを起動してください。

### 手順

1.  **作業ディレクトリへの移動**

    コマンドプロンプトやターミナルを開き、以下のコマンドで `0818` ディレクトリに移動します。

    ```sh
    cd C:\Users\kageyama\0818
    ```

2.  **ローカルWebサーバーの起動**

    次に、以下のコマンドを実行して、Webサーバーを起動します。(`npx` はNode.jsに付属しているツールで、一時的にパッケージをダウンロードして実行します)

    ```sh
    npx http-server
    ```

3.  **ブラウザで確認**

    サーバーが起動すると、ターミナルに `http://127.0.0.1:8080` や `http://localhost:8080` のようなURLが表示されます。
    
    このURLをコピーしてWebブラウザで開いてください。

    正しく表示されれば、プルダウンメニューが機能するようになっているはずです。

## 補足

- サーバーを停止するには、ターミナルで `Ctrl + C` を押してください。
- Node.js/npmがインストールされていない場合は、先にインストールが必要です。
