# デバッグレポート: APIプリセット読み込みエラー

## 1. 現象
`index.html` を開いた際、プルダウンメニュー（サンプルAPI選択肢）が表示されず、画面に以下のエラーメッセージが表示される。

> APIプリセットの読み込みに失敗しました。
> ./data/presets.jsを確認してください。

## 2. 原因
**`data/presets.js` ファイルのエンコーディング不正（文字化け）による構文エラー。**

- **詳細**: `data/presets.js` に日本語（全角文字）が含まれていますが、このファイルが Shift_JIS 等の UTF-8 以外の文字コードで保存されていました。
- HTML側では `<meta charset="utf-8" />` が指定されているため、ブラウザは JS ファイルを UTF-8 として読み込もうとし、文字化けが発生。結果として JavaScript の構文エラー（SyntaxError）となり、データの読み込みが中断されました。
- これにより、`script.js` が期待する `window.API_PRESETS` 変数が定義されず、エラー画面が表示されていました。

## 3. 対策（実施済み）
破損していた `data/presets.js` を、正常なデータ元である `data/presets.json` を使用して修復しました。

- **処置内容**: `data/presets.json` (UTF-8) の内容を読み取り、正しい JavaScript 形式 (`window.API_PRESETS = [...];`) に変換した上で、**UTF-8 エンコーディング** で `data/presets.js` を再作成（上書き）しました。

## 4. 検証方法
以下の手順で修正が反映されたか確認してください。

1. ブラウザで `index.html` を開いているタブを **再読み込み（リロード）** してください。
   - ※ ブラウザのキャッシュにより修正前のファイルが読み込まれるのを防ぐため、**スーパーリロード**（Windows: `Ctrl` + `F5`, Mac: `Cmd` + `Shift` + `R`）を行うことを推奨します。
2. 画面左上の「① リクエストを作る」パネルにある「サンプルAPI」プルダウンをクリックしてください。
3. 「Frankfurter（為替）」や「WorldTimeAPI（時刻）」などのリストが正しく表示され、選択できるようになっていれば完了です。

## 5. 今後の運用について
- 今後 `data/presets.js` を手動で編集・保存する際は、お使いのエディタ（メモ帳、VS Code等）で **文字コードが「UTF-8」になっていること** を必ず確認してください。
- Shift_JIS (ANSI) で保存すると、再度同様の文字化けエラーが発生します。
