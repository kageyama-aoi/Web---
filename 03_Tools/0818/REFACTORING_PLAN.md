# リファクタリング計画：API Learning Lab

## 1. 目的

現在のアプリケーションは、すべてのロジック、スタイル、構造が単一のHTMLファイルに詰め込まれています。これはポータビリティに優れる一方で、機能が豊富になるにつれて以下の問題が生じます。

- **可読性の低下**: ファイルが長大になり、特定のコード箇所を見つけるのが困難になる。
- **メンテナンス性の悪化**: CSSの修正がJavaScriptのロジックに、あるいはその逆に意図しない影響を与えるリスクがある。
- **拡張性の限界**: 新機能の追加やデータ（APIプリセット）の更新が煩雑になる。

このリファクタリングでは、これらの問題を解決し、将来の機能追加やメンテナンスを容易にすることを目的とします。

## 2. 提案するファイル構成

現在の単一ファイル構成から、ウェブ開発の標準的なプラクティスである「関心の分離」に基づいた以下の構成に変更します。

```
/0818/
├── 景山傑作_api学習Tool.html  (<- 現在のファイル。最終的にindex.htmlに置き換えられる)
├── index.html               (構造)
├── style.css                (見た目)
├── script.js                (動作)
├── data/
│   └── presets.json         (データ)
├── README.md
└── CHANGELOG.md
```

## 3. 主要な変更点と理由

### a. `index.html` (HTML)
- **役割**: アプリケーションの骨格、つまりDOM構造のみを定義します。
- **変更点**: 現在のファイルから`<style>`タグと`<script>`タグの内容をすべて削除し、代わりに外部ファイルを読み込むための`<link>`タグと`<script>`タグを配置します。

### b. `style.css` (CSS)
- **役割**: アプリケーションのすべての見た目（レイアウト、色、フォントなど）を一元管理します。
- **変更点**: 元のHTMLファイルにあった`<style>`内のCSSコードをすべてこのファイルに移動します。

### c. `script.js` (JavaScript)
- **役割**: アプリケーションのすべての動作（ボタンのクリック、API通信、DOM操作など）を一元管理します。
- **変更点**: 元のHTMLファイルにあった`<script>`内のJavaScriptコードをすべてこのファイルに移動します。また、APIプリセットのデータを外部ファイルから読み込むため、`fetch` API を使った非同期処理をスクリプトの冒頭に追加します。

### d. `data/presets.json` (データ)
- **役割**: アプリケーションのデータ（APIプリセット情報）を保持します。
- **理由 (CSVではなくJSONを選ぶ理由)**:
  - **階層構造**: APIプリセットのデータは、パラメータ、ヘッダー、スキーマといった階層的な情報を含んでいます。JSONはこのような複雑な構造を自然に表現できますが、CSVは単純な二次元の表データにしか適していません。
  - **JavaScriptとの親和性**: JSONはJavaScriptのオブジェクト記法とほぼ同じであるため、プログラムで非常に扱いやすい形式です。

## 4. 実行手順

以下の手順でリファクタリングを実施します。

1.  **`data/presets.json` の作成**: `script.js` 内の `presets` 配列をこの新しいファイルに移動し、JSON形式として保存します。
2.  **`style.css` の作成**: 元のHTMLから`<style>`タグの中身をすべてこのファイルにコピー＆ペーストします。
3.  **`script.js` の作成と修正**: 
    - 元のHTMLから`<script>`タグの中身をすべてこのファイルに移動します。
    - スクリプトの冒頭で `fetch('./data/presets.json')` を使用して、APIプリセットを非同期で読み込むように修正します。
    - プリセットデータ読み込み後に、アプリケーションの初期化処理（`loadPresets()`など）が実行されるように、処理の順序を調整します。
4.  **`index.html` の作成**: 
    - 元のHTMLファイルをコピーして`index.html`を作成します。
    - `<style>`と`<script>`の中身を空にし、代わりに`<link rel="stylesheet" href="style.css">`と`<script src="script.js" defer></script>`を記述して外部ファイルを読み込むように変更します。
5.  **動作確認と旧ファイルの削除**: 新しい構成でアプリケーションが完全に動作することを確認した後、古い `景山傑作_api学習Tool.html` を削除します。
