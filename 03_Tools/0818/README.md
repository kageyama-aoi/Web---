# API学習ツール

このプロジェクトは、APIの動作を学ぶための単一ファイルのHTMLウェブアプリケーション「API Learning Lab」です。ユーザーがHTTPリクエストを構築・送信し、そのレスポンスを調査することで、APIの仕組みを実践的に学べるように設計されています。

## 主な機能

*   **HTTPリクエストビルダー**: URL、HTTPメソッド（GET, POSTなど）、クエリパラメータ、ヘッダー、リクエストボディを自由に設定し、カスタムリクエストを構築できます。
*   **プリセット**: 為替レート、天気、各国の祝日など、すぐに試せる様々な公開APIが事前に設定されています。
*   **レスポンスインスペクター**: APIレスポンスに関する詳細な情報を確認できます。
    *   ステータスコード（例: 200 OK, 404 Not Found）
    *   レスポンスタイム、サイズ、`Content-Type`
    *   レスポンスヘッダー
    *   レスポンスボディ（Rawテキスト形式と整形済みJSON形式の両方に対応）
*   **cURLコマンド生成**: 構築したリクエストと同等の`curl`コマンドを自動生成します。Bash、PowerShell、cmd.exeの構文に対応しており、コマンドラインでのAPI操作の学習に役立ちます。
*   **OAuth 2.0 PKCE フロー支援**: 安全な認証フローであるOAuth 2.0の認可コードグラント（PKCE付き）を実演するユーティリティが含まれています。
*   **教育コンテンツ**: アプリケーションには、使い方ガイド、クイックスタート、ハンズオン課題、CORSエラーやAPIキー管理といった一般的な問題に対するトラブルシューティングのヒントが組み込まれています。
*   **API仕様のヒント**: 各サンプルAPIで利用可能なクエリパラメータやボディの仕様、公式ドキュメントへのリンクを表示し、学習をサポートします。

## 使い方

1.  `景山傑作_api学習Tool.html` ファイルを最新のウェブブラウザで開きます。
2.  ドロップダウンリストからサンプルAPIを選択すると、リクエスト情報が自動的に入力されます。
3.  または、カスタムAPIエンドポイントのURLを直接入力します。
4.  必要に応じて、クエリパラメータ、ヘッダー、リクエストボディを追加・修正します。
5.  **「▶ 送信」** ボタンをクリックしてリクエストを実行します。
6.  右側のパネルに表示される結果を確認します。JSON、Rawテキスト、ヘッダーのタブを切り替えて、完全なレスポンスを調査できます。
