6. テーマ切替（JS応用・保存）

プレビュー（保存あり）

選択は localStorage に保存され、再読込で復元されます。
(function(){
  const wrap = document.getElementById("mini-theme-persist");
  const key = wrap.dataset.key || "mini-theme";
  const saved = localStorage.getItem(key);
  if(saved) wrap.setAttribute("data-theme", saved);
  wrap.querySelectorAll("[data-mini-theme]").forEach(btn => {
    btn.addEventListener("click", () => {
      const mode = btn.dataset.miniTheme;
      wrap.setAttribute("data-theme", mode);
      localStorage.setItem(key, mode);
      wrap.querySelectorAll("[data-mini-theme].active").forEach(b => b.classList.remove("active"));
      btn.classList.add("active");
    });
  });
})();
保存キーを data-key で変えれば、他のプレビューと衝突しません。

10. タブUI

プレビュー（クリックでタブ切替）

ARIAロール（tablist/tab/tabpanel）で構造を示し、選択中タブに aria-selected="true" を付けます。

  • ボタンに aria-controls で対象パネルIDを紐づけ。
  • 選択切替で hidden の出し入れ。

キーボード操作（←→）を付けるとより親切です。今回はクリック切替の最小実装。

<div class="tabs" data-tabs>
  <div class="tablist" role="tablist">
    <button class="tab" role="tab" aria-selected="true" aria-controls="p1" id="t1">概要</button>
    <button class="tab" role="tab" aria-selected="false" aria-controls="p2" id="t2">使い方</button>
  </div>
  <div class="tabpanel" role="tabpanel" id="p1" aria-labelledby="t1">...</div>
  <div class="tabpanel" role="tabpanel" id="p2" aria-labelledby="t2" hidden>...</div>
</div>
// イベント委譲で、ページ内の全タブUIを制御
document.addEventListener("click", (e)=>{
  const btn = e.target.closest(".tabs [role='tab']");
  if(!btn) return;
  const wrap = btn.closest(".tabs");
  wrap.querySelectorAll("[role='tab']").forEach(t => t.setAttribute("aria-selected", String(t===btn)));
  wrap.querySelectorAll("[role='tabpanel']").forEach(p => p.hidden = true);
  const id = btn.getAttribute("aria-controls");
  wrap.querySelector("#"+id).hidden = false;
});

const ICONS = {
  info: '<svg...>...</svg>', /* アイコン定義 */
  success: '<svg...>...</svg>',
  error: '<svg...>...</svg>',
};
function spawnToast(area, message, type = "info") {
  const el = document.createElement("div");
  el.className = "toast " + type;
  el.setAttribute("role", "status");
  const icon = ICONS[type] || ICONS.info;
  el.innerHTML = `${icon}<span>${message}</span>`;
  area.appendChild(el);
  setTimeout(() => {
    el.classList.add('closing');
    el.addEventListener('animationend', () => el.remove(), { once: true });
  }, 2500);
}
// ボタンクリックでトーストを生成する部分は同じです
