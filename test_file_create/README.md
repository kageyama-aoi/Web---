# 🧪 サンプルファイル生成アプリ（統合版）

## 概要

このアプリケーションは、様々な形式のサンプルファイルをブラウザ上で手軽に生成・ダウンロードできるツールです。CSV、TSV、JSON、YAML、XML、Markdown、TXT、HTML、SQL、そして固定長（EDI対応）といった多様なフォーマットに対応しており、開発やテストにおけるデータ準備の効率化を目的としています。

## 機能

*   **対応フォーマット:**
    *   CSV (カンマ区切り)
    *   TSV (タブ区切り)
    *   JSON
    *   YAML
    *   XML
    *   Markdown
    *   TXT
    *   HTML
    *   SQL (CREATE TABLE と INSERT 文)
    *   固定長 (EDI対応)
*   **プリセット機能:** 事前に定義されたデータスキーマとサンプルデータ（例: 講師謝礼追加、EDI新規会員データ取込、SMBC買取状態読込）を選択できます。
*   **出力設定:**
    *   **区切り文字:** CSV/TSV形式でカンマまたはタブを選択できます。
    *   **ヘッダ行:** CSV/TSV/Markdown形式でヘッダ行の出力有無を選択できます。
    *   **改行コード:** LF (`
`)、CRLF (`
`)、CR (`
`) から選択できます。
*   **プレビュー機能:** 生成されるファイルのリアルタイムプレビューを表示し、ファイル名、サイズ、行数を確認できます。
*   **ダウンロード機能:** 生成されたファイルを指定したファイル名でダウンロードできます。
*   **EDI固定長ファイル生成とバリデーション:**
    *   「2000_1_1｜EDI新規会員データ取込」プリセット選択時、EDI仕様（100桁・ヘッダ/データ/トレーラー/エンド）に準拠した固定長ファイルを生成します。
    *   EDI固定長ファイル生成時には、カード有効期限、会員番号、カード番号、性別、生年月日、申込日などのデータに対する簡易バリデーション警告が表示されます。

## 使い方

1.  **プリセットの選択:** 左側の「設定」パネルにある「プリセット」ドロップダウンから、生成したいデータの種類を選択します。
2.  **フォーマットの選択:** 「フォーマット」セクションで、CSV、JSON、固定長など、出力したいファイル形式のラジオボタンを選択します。
3.  **各種設定:** 必要に応じて、「区切り」「ヘッダ行」「改行コード」のオプションを調整します。
4.  **ファイルの生成とプレビュー:** 設定を変更すると、右側の「出力プレビュー」エリアにリアルタイムで生成されたファイルの内容が表示されます。
5.  **ダウンロード:** 「再生成」ボタンでプレビューを更新し、「ダウンロード」ボタンをクリックすると、生成されたファイルがダウンロードされます。

## ファイル構成

このアプリケーションは、役割ごとにファイルが分割されています。

*   `サンプルファイル生成アプリ.html`: アプリケーションのメインとなるHTMLファイルです。画面の骨格を定義しています。
*   `style.css`: アプリケーション全体のデザインを定義するCSSファイルです。
*   `src/`: アプリケーションの主要なJavaScriptコードが格納されているディレクトリです。
    *   `script.js`: アプリケーションのメインとなるJavaScriptファイルです。各モジュールを読み込み、UIイベントの監視や画面全体の制御を行います。
    *   `ui.js`: UI操作に関連するヘルパー関数（DOM要素の取得、設定値の読み取りなど）をまとめたモジュールです。
    *   `data/presets.js`: サンプルデータの定義（スキーマや実際のデータ）が格納されているモジュールです。
    *   `formatters/`: 各ファイル形式への変換ロジックを持つモジュールが格納されているディレクトリです。
        *   `csvFormatter.js`, `jsonFormatter.js`, `ediFormatter.js` など、各形式に対応したファイルが含まれます。
    *   `utils/stringUtils.js`: 文字列のパディングやクォーテーションなど、汎用的な文字列操作関数をまとめたモジュールです。
*   `README.md`: このファイルです。アプリケーションの概要や使い方を説明します。
*   `REFRACTORING_PLAN.md`: 初期コードから現在のモジュール構成へリファクタリングした際の計画書です。

## 開発環境のセットアップと実行

このアプリケーションは、外部ライブラリに依存していないため、依存関係のインストール（`npm install`など）は不要です。

ブラウザで `サンプルファイル生成アプリ.html` を直接開いても動作しますが、ESモジュールの制約により、ローカル開発サーバー経由でのアクセスが推奨されます。

1.  **開発サーバーの起動:**
    `http-server` がインストールされている場合、以下のコマンドでサーバーを起動できます。
    ```bash
    npx http-server . -o
    ```
    このコマンドは、現在のディレクトリをルートとしてHTTPサーバーを起動し、自動的にブラウザでアプリケーションを開きます。

## 備考/特記事項

*   「固定長」フォーマットは、選択されたプリセットのフィールド定義に基づいて、数値項目は左ゼロ埋め、文字項目は右空白埋めでパディングされます。
*   特に「2000_1_1｜EDI新規会員データ取込」プリセットで「固定長」を選択した場合、EDI仕様に合わせた専用の生成ロジックが適用され、データ長や形式に関する簡易バリデーション警告が表示されることがあります。これは、生成されるデータがEDIの要件を満たしているかを確認するためのものです。
