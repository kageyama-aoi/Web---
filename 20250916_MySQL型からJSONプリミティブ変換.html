MySQL型 → JSONプリミティブ（純出力）

変換の方針（要点）
  • 整数型（INT/SMALLINT/BIGINT…） → number
  • 浮動小数（FLOAT/DOUBLE/DECIMAL/NUMERIC） → number
  • TINYINT(1) / BOOLEAN → boolean
  • 文字列（CHAR/VARCHAR/TEXT/ENUM…） → string
  • SET → array
  • 日付/時刻（DATE/TIME/DATETIME/TIMESTAMP） → string
  • JSON / GEOMETRY系 → object
  • BLOB/BINARY系 → string（base64などで表現する想定）
  • 不明な型は string にフォールバック
